# AI Design System Entry Point

Before creating or modifying Dylan Cornelius / DCMLLC branded web pages or graphical assets in this repository:

1. Read `/design-system/README.md` first.
2. Read and follow `/design-system/BRAND.md` for invariant brand rules.
3. Use `/design-system/tokens.css` for canonical visual values instead of copying arbitrary legacy CSS.
4. Use `/design-system/components.html` as the visual precedent for reusable components and page patterns.
5. If the deliverable is channel-specific (Elementor, Gutenberg, WordPress post/page, featured image, scheduling CTA, etc.), read and follow `/design-system/SCHEMES.md`.
6. Follow the source-of-truth precedence defined in the README.
7. Treat `/design-system/AUDIT.md` as historical evidence only; it does not override canonical rules.
8. Use `/design-system/ROADMAP.md` to distinguish completed rules from open design-system work.
9. Do not duplicate canonical design-system prose in this file. Canonical rules belong in `/design-system/`.

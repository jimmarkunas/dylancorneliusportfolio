# AI Design System Entry Point

Before creating or modifying Dylan Cornelius branded web pages or graphical assets in this repository:

1. Read `/design-system/README.md` first.
2. Read and follow `/design-system/BRAND.md`.
3. Use `/design-system/tokens.css` for canonical visual values instead of copying arbitrary legacy CSS.
4. Follow the source-of-truth precedence defined in the README.
5. Treat `/design-system/AUDIT.md` as historical evidence only; it does not override canonical rules.
6. Once `/design-system/components.html` and `/design-system/references/` exist, read and follow them before making component-level or reference-dependent visual decisions.
7. Do not duplicate canonical brand rules in this file. Canonical rules belong in `/design-system/`.

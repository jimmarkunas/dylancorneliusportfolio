# AI Design System Entry Point

Before creating or modifying Dylan Cornelius branded web pages or graphical assets in this repository:

1. Read `/design-system/README.md` first.
2. Follow the source-of-truth precedence defined there.
3. Do not infer that existing CSS or Figma treatments are approved merely because they exist.
4. Once `/design-system/BRAND.md`, `/design-system/tokens.css`, `/design-system/components.html`, and `/design-system/references/` exist, read and follow them before making visual decisions.
5. Do not duplicate canonical brand rules in this file. Canonical rules belong in `/design-system/`.
